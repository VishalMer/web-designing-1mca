# Web Designing - MCA Semester 1 🌐

Welcome to my Web Designing repository! This workspace contains all the classwork, practical exercises, and lab tasks completed during the first semester of my Master of Computer Applications (MCA) program.

## 📌 About This Repository

The purpose of this repository is to track my progress and maintain a well-organized archive of the web technologies learned in class. It covers core front-end concepts ranging from basic layouts to responsive frameworks.

## 🛠️ Technologies & Concepts Covered
*   **HTML5 & CSS3:** Semantic markup and advanced styling.
*   **CSS Layouts:** Flexbox and CSS Grid.
*   **Frameworks:** Bootstrap for responsive design.
*   **Scripting:** JavaScript basics.

## 📁 Folder Structure & Naming Convention

To keep things organized chronologically, each day's classwork is stored in its own dedicated folder. The folders are named using the `task_date` format (e.g., `flex_Jul28`). 

**Additional Folders:**
*   `images/` - Directory for storing all static image assets used across the HTML files.
*   `Landing_page/` - A normal landing page created for practice basic concepts.
*   `Nexus/` - A dummy website named Nexus created using HTML5, CSS3 and Vanilla JavaScript.

## 🚀 How to Run Locally

1. Clone the repository to your local machine using the following command:
   `git clone https://github.com/VishalMer/web-designing-1mca.git`
2. Open the project directory in your preferred IDE (like WebStorm or VS Code).
3. Open any `.html` file directly in your web browser or run it using a local development server (like Live Server or Laragon).
